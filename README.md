# Banesco Formación · previsualización académica independiente

Este repositorio contiene únicamente una versión estática de la landing informativa. No incluye código PHP, backend, bases de datos, credenciales, `.env`, registros ni autenticación. El acceso indica que las funciones privadas estarán disponibles en la versión completa.

El sitio se publica desde GitHub Actions. El workflow prepara un artefacto con `index.html` y los recursos locales de `assets/`; ningún archivo del sistema PHP/MVC forma parte del artefacto.

Prototipo académico independiente: no es una plataforma oficial de Banesco ni implica afiliación, autorización, patrocinio o implementación institucional.
